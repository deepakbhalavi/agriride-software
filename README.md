## 🎯 Project Overview

AgriRide is a **Smart Shared Transportation Scheduling Platform** designed to solve a key problem faced by farmers in rural areas: the high cost and inefficiency of transporting agricultural produce to markets individually.

### The Problem
- Farmers individually hire transport vehicles → high cost per farmer
- Empty vehicle capacity is wasted
- No system to coordinate shared trips between nearby farmers

### Our Solution
A rule-based compatibility matching engine that:
1. Groups farmers with similar destinations, pickup locations, and time windows
2. Allocates a shared vehicle
3. Splits costs fairly based on load weight
4. Provides real-time trip tracking and notifications

## ✨ Core Features

### 👨‍🌾 Farmer Portal
- Register & manage farmer profile with location
- Create transport bookings (produce type, quantity, destination, time window)
- Browse and join shared trips
- Real-time trip tracking
- Payment management
- Booking history

### 🚛 Driver Portal
- Register & manage driver profile
- Add and manage vehicles (capacity, type, registration)
- View and accept/reject available shared trips
- Update trip status (pickup → in transit → delivered)
- Earnings dashboard

### 🔧 Admin Portal
- Full platform dashboard with statistics
- Manage all users (activate/deactivate)
- Configure matching algorithm parameters
- View all bookings, trips, and payments
- Generate reports

### 🤝 Smart Matching Engine
- Rule-based (NOT machine learning) for transparency
- Groups bookings by destination proximity
- Validates geographic pickup distance
- Checks time-window overlap
- Verifies vehicle capacity fit
- Calculates compatibility score (0–100%)

## 🤖 Matching Algorithm

The matching engine (`backend/services/matching_engine.py`) is explicitly **rule-based** (not ML) for academic transparency and auditability.

### Algorithm Steps:
1. **Filter** active bookings with status `REQUESTED`
2. **Group** by destination market (same name OR within `destination_radius_km`)
3. **Validate** each candidate group:
   - Geographic distance between all pickup points ≤ `max_pickup_distance_km`
   - Time-window overlap ≥ `min_time_overlap_min`
   - Total quantity ≤ best available vehicle capacity
4. **Score** compatibility using configurable weights:

| Factor | Default Weight |
|--------|---------------|
| Destination compatibility | 30% |
| Geographic proximity | 25% |
| Time compatibility | 20% |
| Capacity compatibility | 25% |

5. **Result:** `MATCHED` / `PARTIALLY_MATCHED` / `NOT_MATCHED`

> Architecture is designed to allow ML demand-prediction extension in future iterations.

## 🚀 Getting Started (Local Setup)

### Prerequisites
- Python 3.9+
- Node.js 18+
- Git

### 1. Clone the Repository
```bash
git clone https://github.com/deepakbhalavi/agriride-software.git
cd agriride-software
```

### 2. Backend Setup
```bash
cd backend

# Create virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

# Install dependencies
pip install -r requirements.txt

# Configure environment
copy .env.example .env       # Windows
# cp .env.example .env       # macOS/Linux
# Edit .env if needed (SQLite is default — no changes needed)

# Start backend server
python -m uvicorn main:app --reload
```

Backend runs at: **http://127.0.0.1:8000**  
API Docs at: **http://127.0.0.1:8000/docs**

### 3. Load Sample Data (Optional)
```bash
# In the backend directory with venv activated
python seed_data.py
```

### 4. Frontend Setup
```bash
cd frontend

# Install dependencies
npm install

# Start dev server
npm run dev
```

Frontend runs at: **http://localhost:5173**
